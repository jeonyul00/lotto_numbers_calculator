## 🎉 로또 계산기

---

### ⚠️ **안내** ⚠️

🚫 이 로또 계산기는 **재미로 제작**되었습니다.  
🚫 분석 결과는 **과거의 데이터만을 바탕**으로 하였습니다.  
🚫 로또는 **운을 기반으로 한 게임**이며, 모든 번호의 확률은 동일합니다.  
🚫 과거 데이터를 바탕으로 미래의 결과를 예측하는 것은 권장되지 않습니다.  
👊 그럼에도 불구하고 저는 한 줄기 희망을 부여잡고 매주 구매해 보겠습니다.

---

### 🎯 기능

1. **역대 로또 당첨 번호 조회**: 각 자리마다 당첨 확률이 가장 높은 수를 추출합니다.
2. **당첨 확률 분석**: 자리와 관계없이 당첨 확률이 가장 높은 수를 추출합니다.
